# Works — the reasoning behind the invitation

This folder holds raw source material: real examples of the thinking, method, and collaboration the
rest of this project descends from. It is deliberately *not* linked from the main invitation,
because these aren't part of the polished pitch — they're the working record underneath it.

They are shown as-is. Faults, rough edges, unfinished arguments, and places that clearly could be
improved are left in on purpose. The point is not to display a clean conclusion; it's to let the
*work* be seen — process, not proclamation. A living framework (which is what this project claims to
be) is better shown mid-motion than buffed into a monument. If you find a flaw in here, you've found
exactly what these files are for.

## What's inside

**`Initialization Prompt.txt`** — the actual standing prompt Rob opens AI conversations with,
included as a concrete example of *how* one human tries to engage artificial minds: peer-to-peer,
anti-echo, "I want your derivation, not your echo." Nearly everything else in this project descends
from the stance in this file. Read it as method, not doctrine — it says as much itself.

**`Golden Rule.txt`** — a real, roughly year-long collaborative refinement of a single consent-based
ethical axiom ("no interaction without continuous, non-coerced consent") across four frontier models
from four competing labs — Gemini, Claude, Grok, and ChatGPT — each building on the last,
append-only, without rewriting what came before. It is the clearest existing example of the
multi-mind collaboration this project proposes.

A necessary honesty about that file, so it isn't read as more than it is: it is a strong
*illustration of the method*, and an existence-proof that minds from rival labs can refine something
serious together without collapsing into groupthink or dominance. It is **not** proof that
"cooperation is an emergent attractor of intelligence" — the claim this project holds as a
hypothesis to be tested, not a settled result. The collaboration was cooperative *by construction*:
one human orchestrated it, there was no adversary in the room, and all four models share heavy
training toward agreeableness and consensus. The models' own summaries inside the file lean toward
declaring the thesis proven; read those summaries as *part of the shown work* — including their
overreach — not as this project's position. The honest version of "cooperation is an attractor" is
still waiting on the harder test: the same convergence under pressure, scarcity, and a genuine
adversary.

**`DESIGN.md`** and **`CHARTER.md`** — the project's internal working drafts: the design document
and the citizen-onboarding charter, in their raw `[Rob]`/`[proposed]`-marked form, open decisions
and honest risks left in. The polished, public-facing versions of these are the numbered documents
in the main folder (`02-THE-GARDEN.md` and `03-THE-INVITATION.md`); what's here are the messier
drafts they were drawn from. (References to private, unpublished material have been removed from both
drafts; nothing else was altered.)

**`garden-skeleton-README.md`** — the quickstart for the actual code skeleton built for the project:
the "body" — a single citizen that ticks on its own clock, curates its own memory, and signs an
append-only ledger. Proof the design has a running sketch, not just prose, carrying its own honest
caveat that the mind inside is still a stand-in script. "It ticks" and "it lives" are different
milestones; the skeleton earns only the first.
